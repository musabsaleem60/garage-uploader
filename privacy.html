Privacy policy: Garage Uploader

Last updated: 2 November 2026

Who uses this app

Garage Uploader is a private tool. Only the owner of the YouTube channel Muhammad Musab (car restoration animations) signs in to it, to manage that one channel.

What Google data it uses, and why

  • YouTube account access (YouTube Data API): to upload the channel's own videos, set their thumbnails and captions, schedule publish times, and update the channel's own banner, description and keywords.
  • Public comments on the channel's own videos: counted to find which car viewers vote to see restored next. Only the totals are kept; comment text and commenter names are not stored.
  • Public search results and view counts: to see which kinds of car restoration videos are popular this week. Only counts are kept.
  • YouTube Analytics (read only): to read the channel's own view and subscriber statistics for the owner.

It does not change or delete anything on any other channel or Google account, and it does not access email, contacts or files.

Where data is stored

The sign-in token is stored only on the channel owner's own computer. No data is sent to any server other than Google's own APIs.

Sharing

No data is sold, shared with, or transferred to anyone. It is not used for advertising.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends access.
